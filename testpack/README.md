# testpack/ - v1 (SUPERSEDED, kept untouched)

These 12 designs were generated by an earlier engine. They are **not** what the current engine writes: `python3 tools/dst_provenance.py testpack`
reports most of them as **STALE** (stitch-generation changes since: lock length, tatami row ends, region ordering, satin / underlay changes).
All were generated *after* the DST X/Y axis fix (commit 1980975), but they must not be used as a current baseline.

If you already stitched a v1 file, keep your result sheet with its file hash (`sha256sum 12_trims_locks.dst`) - that result describes that exact file, not a v2 file.

**Use `testpack/v2/` for new stitch-outs.** It is generated by the current engine, every file passes the provenance check, and it adds orientation, small running stitch,
jump movement, hoop boundary and one design per (provisional) fabric preset. Procedure: `docs/testing/`.
Regenerate / verify: `docs/testing/regeneration-procedure.md`.
